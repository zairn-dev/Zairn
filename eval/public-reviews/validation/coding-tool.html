Before you start

  1. Load your assigned CSV file (irr-sample-coder-A.csv or -B.csv).
  2. Read each review and tick every code whose theme is substantively present. Multi-label is expected — a review can earn several codes, or none.
  3. Code independently. Do not consult the other coder's sheet, the automatic coder's output, or irr-sample-key.json.
  4. Judge the review text only. The star rating is context, not evidence.
  5. Ignore generic praise ("nice app", "5 stars"), install chatter, and unrelated feature requests. A code applies only when the reviewer makes a real claim about that theme.
  6. When you finish, press Export CSV and return the downloaded file.

Your progress is saved in this browser automatically. You can close the tab and reload the same file later to resume. Roughly 2 hours for 200 reviews.

Practice uses the codebook's own examples with known answers and instant feedback. None of them appear in the real sample. Aim for 12/15 before starting.
